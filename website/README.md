# locate-anything-rs website

The website for [locate-anything-rs](https://github.com/apiplant/locate-anything-rs). Solid 2 RC + Tailwind v4 + Vite, static build, deployed to Cloudflare.

```bash
pnpm install
pnpm dev       # local dev server
pnpm build     # -> dist/
pnpm check     # types only
```
